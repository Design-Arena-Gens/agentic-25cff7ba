# Logic Gates Lab (AND / OR) + Proteus 8 Guide

This is a minimal Next.js app that provides an interactive AND/OR gate simulator and a practical how-to guide for wiring the same circuits in Proteus 8 Professional.

- Simulator: `/` (toggle A/B and see live outputs + truth tables)
- Guide: `/proteus`

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Deploy

This repository is configured for Vercel. Production deployment command:

```bash
vercel deploy --prod --yes --token $VERCEL_TOKEN --name agentic-25cff7ba
```
